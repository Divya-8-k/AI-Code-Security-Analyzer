    # AI Code Security Analyzer

## Project Overview

AI Code Security Analyzer is a security analysis tool that examines source code and identifies potential security issues. It combines static code analysis with AI-based analysis to assess code quality, security risks, and generate a final risk report.

## Features

* Source code analysis
* Security vulnerability detection
* Code complexity analysis
* Risk score calculation
* Security issue identification
* Final risk report generation
* CSV-based risk report

## Technologies Used

* Python
* Google Colab
* Static Code Analysis
* AI / Machine Learning
* GitHub

## Project Workflow

1. Upload or provide the source code.
2. Analyze the code using static analysis techniques.
3. Identify possible security issues.
4. Calculate the security risk score.
5. Generate the final risk report.
6. Export the results as a CSV file.

## Output

The project generates a final security risk report:

`final_risk_report.csv`

The report contains the security analysis results and risk information for the analyzed code.

## How to Run

1. Open the `.ipynb` file in Google Colab.
2. Run the notebook cells in order.
3. Provide the required source code/input.
4. Wait for the security analysis to complete.
5. The final risk report will be generated as a CSV file.
